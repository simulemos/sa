# Simulación Avanzada — Ingeniería Civil Industrial, PUCV

Repositorio de material del curso electivo de **Simulación Avanzada**, impartido en la Escuela de Ingeniería Industrial de la Pontificia Universidad Católica de Valparaíso.

## Descripción del Curso

La asignatura busca ejercitar todos los aspectos asociados al desarrollo de un proyecto de simulación de sistemas reales. Profundiza conocimientos de simulación de eventos discretos, estudiando cómo funcionan los lenguajes de simulación y cómo interactúan con otras aplicaciones, mediante el aprendizaje de objetos avanzados en la plataforma **Simio**.
